# SofaPad 安装与使用：Windows / Mac

**电脑安装一次，手机打开浏览器。** 手机不需要安装 App，不需要注册账号，也不需要输入构建命令。

[返回产品介绍](https://keyzhao0118.github.io/sofapad/) · [0.10.0 发布页面](https://github.com/keyzhao0118/sofapad/releases/tag/v0.10.0)

## 先选你的电脑

| 电脑 | 下载 | 要求 |
| --- | --- | --- |
| Windows | **[EXE 安装程序](https://github.com/keyzhao0118/sofapad/releases/download/v0.10.0/SofaPad-0.10.0-windows-x64-setup.exe)** | Windows 11，x64（Intel / AMD） |
| Mac | **[PKG 安装程序](https://github.com/keyzhao0118/sofapad/releases/download/v0.10.0/SofaPad-0.10.0-macos-arm64.pkg)** | macOS 13+，Apple Silicon（M 系列芯片） |

把安装文件下载到**要控制的电脑**。如果现在在手机上阅读，请把这个页面地址发到电脑后再下载。GitHub 的“Source code”是源代码，日常使用不用下载。

Mac 芯片可在“苹果菜单 → 关于本机”查看；Intel Mac 需自行构建。Windows 10 / ARM64 尚未验证。安装包包含运行所需内容，无需另装 .NET、Node.js 或 Python。

## Windows 开始使用

1. 双击下载的 EXE，按向导完成安装。管理员授权用于安装文件和配置防火墙；SofaPad 本身以普通用户运行。
2. 从开始菜单打开 SofaPad。**没有主窗口是正常的**：在右下角通知区域找图标，可能藏在 **∧** 中；双击查看连接说明和地址。
3. 手机和电脑连接同一个家庭 Wi-Fi。在“设置 → 网络和 Internet”中打开当前 Wi-Fi 或以太网连接的属性，将家庭网络设为**专用网络**。安装器仅为专用网络中的同子网设备添加本应用的防火墙规则。
4. 按下方“手机连接”打开地址。

[Windows 详细使用、排障和卸载](windows-installation.md)

## Mac 开始使用

1. 双击下载的 PKG，按向导安装到“应用程序”，再打开 SofaPad。**没有常驻窗口和 Dock 图标是正常的**：图标在屏幕顶部菜单栏。
2. 点击 SofaPad 菜单中的“授予辅助功能权限…”，在“系统设置 → 隐私与安全性 → 辅助功能”中开启 SofaPad。此权限用于产生鼠标和键盘输入，不需要录屏权限。
3. 手机和 Mac 连接同一个家庭 Wi-Fi。点击菜单栏 SofaPad 图标，找到 .local 或 IP 连接地址。
4. 按下方“手机连接”打开地址。

[Mac 详细使用、授权和卸载](macos-installation.md)

## 手机连接

在手机 Safari、Chrome 等浏览器的地址栏中，输入 **SofaPad 在电脑上显示的地址**。

例如：`http://192.168.1.23:9876/`。这里只是格式示意，请用你自己的实际地址，保留 `http://` 和 `:9876`，不要改成 HTTPS 或把它当搜索词。

看到触控板和“可以开始操作”后，用单指滑动手机屏幕；电脑指针跟着动，就成功了。

**GitHub Pages 是介绍与下载页，不是控制入口。** 控制页面由你电脑上的 SofaPad 提供，所以更换电脑时，要打开另一台电脑显示的地址。使用过程中电脑必须保持已登录、解锁和唤醒。

## 先试这三个操作

1. **移动和点击**：手机上单指滑动移动指针，轻点执行左击，快速轻点两次执行双击。
2. **滚动页面**：双指上下或左右滑动；也可以用单指沿左右边缘上下滚动。
3. **输入中文**：先点中电脑上的搜索框，再点手机右上角键盘按钮，像平时一样选词。提交的文字会发到电脑当前焦点，手机输入框随即清空。

## 更多手势和输入

| 手机操作 | 效果 |
| --- | --- |
| 双指轻点，或单指按住约半秒 | 右键单击 |
| 三指一起滑动 | 按住左键拖动 |
| 轻点一次 → 再按住稍停 → 滑动 | 单指拖动；第二次按下后先稍停，抬手结束 |
| 手机键盘删除键 / 回车 | 向电脑发送 Backspace / Enter |
| 右上角收起箭头、从箭头下滑或点空白触控区 | 收起手机键盘 |
| 左上角设置 | 调整指针、滚动、自然滚动及手机常亮 |

输入只发到电脑当前焦点，SofaPad 不读取原有内容，也不会自动寻找输入框。回车是换行还是提交，由电脑应用决定。手机键盘支持听写时可尝试语音输入，实际表现受输入法影响。断线后未确认的文字不会自动重发。

手感设置保存在当前电脑，下次连接自动恢复，多部手机同步。常亮只在前台尝试保持屏幕唤醒，低电量模式和浏览器策略可能阻止它；请看设置中的状态并在手机上实际确认。

## 首次安装提示

0.10.0 是开发预览，Windows 安装包未代码签名，Mac 安装包未经过 Apple 公证。

| 系统提示 | 如何处理 |
| --- | --- |
| Windows：未知发布者 / Windows 已保护你的电脑 | 确认下载来自本仓库 Release，再查看“更多信息”里的“仍要运行”（如系统提供）。安装时会请求管理员授权。 |
| Mac：无法验证开发者 / Apple 无法检查 | 确认下载来源，先尝试打开，然后在“系统设置 → 隐私与安全性”中查看“仍要打开”，按系统提示确认。 |
| 单位电脑的安全策略禁止安装 | 联系管理员，不要关闭全局防护或绕过组织策略。 |

可从发布页面下载 [SHA-256 校验文件](https://github.com/keyzhao0118/sofapad/releases/download/v0.10.0/SofaPad-0.10.0-SHA256SUMS.txt)。备用 ZIP 也在[发布页面](https://github.com/keyzhao0118/sofapad/releases/tag/v0.10.0)：Windows 需完整解压，且不会自动配置防火墙；Mac 解压后把 SofaPad.app 拖入“应用程序”。

## 连接不上时逐项检查

1. **电脑端在运行吗？** Windows 看托盘，Mac 看菜单栏；确认服务已开启，电脑没有锁屏或休眠。
2. **用的是自己电脑的地址吗？** 不要输入本文的示例地址或介绍网站；换网络后重新查看电脑显示的地址。
3. **在同一家庭网络吗？** 避免访客 Wi-Fi、AP 隔离；检查影响本地连接的 VPN。电脑用有线网络也可以，只要与手机处于同一局域网。
4. **Windows 网络是否为专用？** 安装器不会放开公共网络。若使用 ZIP，建议改用 EXE 安装程序来配置防火墙。
5. **Mac 的 .local 地址打不开？** 改用菜单里的 IP 地址，并检查系统防火墙是否允许 SofaPad。
6. **能打开触控板，指针却不动？** Mac 检查辅助功能授权；Windows 回到普通桌面，管理员窗口和 UAC 安全桌面不受控。
7. **文字没进目标框？** 先点中电脑输入框，再在手机打字。部分第三方应用会限制合成输入。

如果仍有问题，请在 [GitHub Issues](https://github.com/keyzhao0118/sofapad/issues) 描述电脑系统、手机系统/浏览器、SofaPad 版本，以及卡在哪一步。无需提交输入文本或剪贴板内容。

## 更新、登录启动和卸载

- **登录启动**：在 Windows 托盘或 Mac 菜单栏菜单中开启“登录时启动”。平时不用时可关闭服务，或退出 SofaPad。
- **更新**：退出旧版，下载相同系统的新版安装包覆盖安装，打开后刷新手机页面。软件没有自动更新。
- **Windows 卸载**：“设置 → 应用 → 已安装的应用 → SofaPad”。移除程序及其防火墙规则，保留用户偏好。详见 [Windows 教程](windows-installation.md)。
- **Mac 卸载**：退出 SofaPad，把“应用程序”中的 SofaPad 移到废纸篓；按需移除登录项及辅助功能授权。详见 [Mac 教程](macos-installation.md)。

## 使用范围

只用于可信家庭局域网。当前无账号、无配对，能访问地址的设备即可控制；连接为明文 HTTP/WS，不要把端口映射到公网。画面仍看电脑或电视，软件不提供屏幕镜像、远程开机或解锁。

自动测试和部分真实输入验证已通过，手机实连、多屏、长期使用仍需要目标设备验收：[Windows 验证](windows-validation.md) · [Mac 验证](validation.md)。
