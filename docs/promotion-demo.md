# 动态宣传页

2026-10-01：宣传页改为“先看演示，再查方法”。本轮只调整 GitHub Pages，不改 App、不更新 0.9.10 安装包。

## 页面结构

- 首屏一句产品定位、下载入口和手机／大屏并排的同步演示。
- 六段动画自动轮播：移动与点击、单手边缘滚动、拖动进度条、中文输入、双击打开照片、长按右击。每段约 8.2 秒。
- 演示支持选择场景、暂停、重播，点步骤可暂停并查看对应状态。
- 三张适用场景卡：客厅看电影、大屏浏览、中文搜索。按钮切换到相应演示。
- 次要能力用三个简短模块说明；安装保留三步；完整手势、输入和设置按需展开，FAQ 默认收起。

## 实现与真实性

`index.html` 提供内联 SVG 设备、场景和无脚本时的静态示意；`site.css` 延续产品的暖灰绿配色；`demo.js` 统一时间线更新手机落指和 Mac 响应，使用 requestAnimationFrame，不请求外部资源。没有真实控制连接、鼠标注入、账号、追踪或媒体下载。

手机界面按实际的顶部设置／键盘按钮、顶部输入条与双侧滚动区域绘制；键盘是原生键盘的示意，并非手机截图。Mac 场景是解释效果的插画，不是屏幕镜像或真实录制。网页明确标注模拟演示；大屏响应和手机选词保持先后关系，选词提交后 Mac 才出现文字，手机输入框随即清空。

双击间隔约 230 ms，右击静止按住约 500 ms；拖动第二次按下后等待约 238 ms 再移动，符合至少 150 ms 的实际拖动判定。移动比例与设备尺寸仅作说明，不承诺真实延迟或速度。

## 动效与访问

- 页面隐藏或演示滚出视口时停止帧循环；恢复时接续，避免补播跳跃。
- 检测 `prefers-reduced-motion` 时默认暂停，展示结果；允许用户主动播放，也可逐步查看。
- 按钮可用键盘操作，当前场景用 `aria-pressed`，当前步骤用 `aria-current`。动画不持续向屏幕阅读器播报。
- 禁用 JavaScript 时显示静态手机／大屏，下载、安装、展开指南与 FAQ 正常使用。

## 本轮验证

独立本地 Chromium 验证通过：320／393／768／1440 px 无整页横向溢出；六段演示的播放、滚动、拖动、选词同步、照片打开和右键菜单结果正确；场景跳转、步骤查看、暂停、重播、减少动态效果及无脚本回退通过；锚点有效、浏览器无脚本错误。实际截图逐项检查。App 的 129 项验证仍对应 0.9.10，此网页更新未重跑未改动的 App 测试。
