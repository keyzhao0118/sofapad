# SofaPad 统一产品文档

产品基线 **v2.0** · 对应应用 **0.2.0 开发预览** · 2026-09-09

本文件是产品范围、交互和验收的唯一开发基线。优先级为：用户最新补充 > [MVP 原稿 v0.2](archive/mvp-v0.2-original.md) > [旧蓝图 v1.3](archive/v0.1/product-blueprint.md) 中仍适用的工程约束。安装、协议和测试记录分别维护细节，不重复定义产品范围。

## 1. 定位与前提

Mac mini 连接电视，iPhone Safari 作为触控板和文字输入端。电视负责显示，手机负责输入，日常可以收起实体键鼠。只安装一个 Mac 菜单栏 App；App 内置网页与局域网服务，不依赖手机 App、云账户、Pages、CDN 或单独网站部署。

Mac 必须已登录、解锁、唤醒，SofaPad 正在运行，并完成辅助功能及必要的局域网授权。Mac 网线、手机 Wi-Fi 可以，只要局域网互通。首次安装、重启后的登录和授权需要用户在 Mac 完成，不属于手机遥控流程。

手机不显示 Mac 画面；用户看电视确认指针、光标、选区和结果。运行目标 macOS 13+，目标浏览器 iPhone Safari（当前建议验证 iOS 17+）；最低实际兼容版本以真机结果为准。

## 2. 完整使用流程

1. Mac 开启服务和限时配对，显示访问地址与二维码；iPhone 扫码打开 Safari。
2. 新页面默认进入触控模式，在电视上移动、点击和滚动。
3. 需要文字时先点选 Mac 的输入位置，再点击手机“输入”。
4. 输入模式同步聚焦文本框，唤起 iPhone 原生键盘，完成中文选词、英文、Emoji 或系统听写。
5. 点击“贴入输入框”，发送完整、已提交的文字。Mac 写入剪贴板后执行一次 Command + V。
6. 手机保留原文并短暂反馈指令状态；用户看电视确认结果，点击“触控”返回。需要搜索时点击 Mac 页面上的搜索按钮。
7. 锁屏／切后台后返回页面，自动尝试重连，继续接受新操作。

## 3. 手机界面

### 3.1 触控模式

触控板铺满**网页可用视口**，无标题栏、底部工具栏或独立鼠标按键。普通 Safari 的浏览器栏与系统区域无法由网页占用。

正常连接只常驻两个悬浮入口：左上角 48 × 48 CSS px 的“手感设置”按钮；右下角“输入”模式按钮。均避开系统安全区域，按钮不占用独立布局行，也不向 Mac 发送鼠标点击。连接异常、权限缺失时才显示提示。

**用户最新补充优先于原稿的“无设置面板”：保留手感设置。** 弹窗只包含指针／拖动速度、滚动速度、自然滚动和恢复默认；关闭后回到整屏触控。倍率范围 0.3–4.0，默认指针与拖动 1.8、滚动 1.4、自然滚动开启。本机浏览器持久化这些设置；轻点阈值、双击规则仍使用内置参数，不增加主题或手势映射设置。

### 3.2 输入模式

只包含文本框、“贴入输入框”和共用的“触控”模式按钮，以及必要的短暂反馈。输入模式隐藏手感设置和触控面，不产生鼠标操作。

切入输入模式必须在用户点击处理函数内同步 focus，适配 visualViewport 的高度及偏移，确保软键盘出现后输入、粘贴、切换仍可用。切回触控时 blur 收键盘。切换、打开设置前清理当前手势；不得产生额外点击。

草稿只驻留当前页面，不写 localStorage、日志或持久化文件。发送后不清空、不自动返回；切换模式保留。关闭、刷新或系统回收页面后不承诺恢复。

## 4. 手势契约

| 手势 | 行为 |
| --- | --- |
| 单指滑动 | 相对移动指针，抬手重落后从 Mac 当前位置继续 |
| 单指轻点 | 一次左击 |
| 连续两次轻点 | 两次点击形成双击，第二击 count=2，不补发整组 |
| 双指轻点 | 所有触点抬起后仅一次右击，容许少量落指时间差 |
| 双指滑动 | 三方向（横、纵、斜）连续像素滚动，默认内容随手指方向移动 |
| 三指滑动 | 在 Mac 当前指针位置按住左键，跟随三指中心的相对位移拖动 |

轻点初始容差 8 px、240 ms；第二指轻点加入窗口 120 ms，双击时间取 Mac 系统配置。双指滚动中心阈值 5 px。手感参数最终由真机校准，这些数值是初始实现参数。

单指明显滑动后不产生点击。第二指加入后停止单指移动；双指先抬一指时阻止余下触点触发新手势，全部抬起再开始。滚动后不右击；触控板避免浏览器滚动、缩放、选字和合成重复点击。

### 三指拖动

- 先用单指定位；第三指须在首次落指后 180 ms 内、双指尚未开始滚动时加入。三指成立时重置中心，落指本身不移动指针、不点击。
- 三指中心移动超过 8 px 才开始：一次 leftMouseDown → 连续 leftMouseDragged。三指仅轻点无操作。
- 任意一指抬起，立即发送一次 leftMouseUp；其余触点全部抬起前不转为移动、滚动或点击。
- 已经双指滚动后加入第三指，取消滚动并等待全部抬起；第四指及更多触点取消当前手势。
- 模式切换、设置弹窗、旋转、pointercancel、捕获丢失、后台和断线清理。Mac 在会话关闭、心跳超时、协议错误、权限丢失、暂停和正常退出时独立尝试释放本应用的左键；不只依赖手机结束包。
- 不支持拖动锁定或抬手续拖。系统强杀、崩溃或已撤权后 OS 拒绝事件不属于可保证的正常释放路径。
- iPhone 系统三指编辑手势可能抢占触摸；返回触控时取消文本焦点有帮助，但不作为兼容性证明。正式可用必须通过目标 iPhone Safari 的横纵拖动及从输入模式返回后的实测。

## 5. 文字输入与执行

发送已提交的完整文本，不逐键传输、不发送候选缓冲，不 trim、翻译、改写、规范化或附加换行。IME 组合中点击粘贴先请求结束选词，等 compositionend 后的最终 input 更新，再读取文本；模式切换或后台取消未发送的等待，不留下延迟粘贴。

空字符串禁用；仅空格或换行也是有效文本。发送期间禁止第二次提交；结束后用户可主动再发。UTF-8 文本上限 12,000 字节，完整 JSON 消息上限 16,384 字节（转义也占空间）。超限明确提示，不自动截断。

Mac 以串行顺序执行：鉴权／请求校验 → 去重 → 写入 NSPasteboard → **仅写入成功后**按下和释放 Command + V → 返回状态。不会激活 SofaPad、扫描输入框、读控件内容、寻找焦点、全选或按 Enter；不恢复旧剪贴板。目标 App 决定粘贴、选区替换、拒绝或过滤行为。

| 结果 | 手机反馈与行为 |
| --- | --- |
| 剪贴板及粘贴指令已执行 | 短暂“粘贴指令已执行”，保留原文；不声称输入成功 |
| 剪贴板写入失败 | 明确未执行粘贴，避免粘贴旧内容 |
| 已发但断线／6 秒未获回执 | “请查看电视确认是否已粘贴”；保留原文，不自动重试 |
| 未连接／未发送 | 禁用或提示尚未发送，不排队 |
| 缺少权限 | 提示在 Mac 授权 |

每次主动提交生成 requestID（进程 epoch + 128-bit 随机值）。Mac 按设备保存摘要与结果，跨 socket 重连保留；同 ID 同文本返回原结果，同 ID 异文本拒绝，不再次执行。每设备至多 1024 个结果，不淘汰旧 ID 后重新执行。达到上限拒绝新请求；重启进程换 epoch，旧请求也拒绝。文本原文不进入服务日志或去重记录，系统剪贴板仍按正常应用行为保留内容。

## 6. Mac 应用与连接

原生菜单栏常驻，日常只展示服务／控制者状态、连接入口、配对／断开／停止及退出。首次授权、网络地址、HTTPS 导入、登录启动与已配对浏览器收在折叠区域，不建设遥控配置中心。执行输入时保持后台，不抢焦点。

保留旧蓝图的工程基础：SwiftPM 单仓库、内置网页、原生 CGEvent、无遥测／云服务、用户显式开关、安装到稳定路径后配置登录启动。使用公开 macOS 生命周期通知；睡眠、显示器休眠或会话切换暂停，恢复后手机自动重连。Mac 主动“断开”、设备撤销及 busy 停止自动重试；用户可按提示重连，不抢占另一控制者。

页面后台主动结束连接；服务端约 6 秒无有效应用消息释放会话，前台重连重新建立 sessionID／seq。移动、滚动和拖动更新按帧累加，点击前先发此前更新；持续背压取消，不囤积或重放旧动作。

## 7. 通信与部署边界

正式使用提供 HTTPS/WSS，最低 TLS 1.2，页面和控制通道同源。Mac 导入 PEM 证书链与对应未加密 PEM 私钥；Safari 必须信任证书链，SAN 覆盖所用 IP／主机名。App 保存私钥于本机用户目录（目录 0700、文件 0600），不上传、不自动安装根证书、不忽略验证、不在 TLS 启动失败时降级。证书配置是首次部署事项；自动签发／续期不在本轮范围。

首次服务关闭。有有效导入材料并成功启用 HTTPS 后记住运行选择；**未加密 HTTP/WS 仅为每次显式选择的开发模式，不满足正式使用保护通信的要求**。从旧 HTTP 切到 HTTPS 使用独立 Secure Cookie，需要重新配对。

只绑定选定 en* 以太网／Wi-Fi 的私有 IPv4，固定端口 9876，显示实际 IP，真实 `.local` 主机名为可选入口。地址／主机名变化停止服务并提示重新开启；IPv6-only、VPN、特殊接口与公网穿透不支持。离线指保留家庭局域网但断开外网，不是断开 Mac 后仍能控制。

配对窗口 5 分钟，256-bit 一次性令牌；首次扫码 URL fragment 在网页启动时清除。凭据 30 天，HttpOnly／SameSite=Strict；HTTPS 增加 Secure／__Host- 前缀。Mac 仅保存凭据哈希，移除立即撤销并断开。精确校验 Host 和 Origin，POST／WS 必须同源，不提供宽泛 CORS。

最多 32 个有效配对、48 个连接；3 秒 hello、HTTP/TLS 接入约 10 秒；单活动控制者。协议 v2 限制会话、递增序号、有限位移、拖动／滚动生命周期、大小和频率，详见 [协议](../Protocol/README.md)。不开放通用命令、任意键码或剪贴板读取接口。

## 8. 明确排除

不做长按、三指拖动之外的三指操作、四指手势、捏合、拖动锁定、独立左右键、方向键／回车／快捷键栏、媒体控制、应用启动、宏、常用文本、主题／手势自定义、多 Mac 管理、远程画面／截图、两端同步编辑、剪贴板历史／恢复、自动全选／提交、互联网远控、开机／唤醒／登录／解锁。

旧版“使用 Mac 屏幕键盘完成输入”退出核心流程；用户仍可自行使用系统功能，但不作为本版实现或验收依赖。

| V-14 | HDMI 切换后坐标、真实撤权与重新登录；无外网时网页仍可重载、连接 |
| V-15 | 干净源码构建／内置网页／许可／签名校验；真机验证后再考虑分发 |

质量目标沿用旧蓝图，均是目标而非已测结果：正常网络端到端 P95 ≤120 ms（高速录像同时拍手机与电视至少 50 次）；RTT P95 ≤30 ms（同一端计时，不能代替端到端）；连续 60 分钟稳定；Mac 空闲 10 分钟平均 CPU <1%。

代码和自动测试通过不等于 iPhone／电视验收通过。[验证记录](validation.md)明确区分两者。真机失败时优先修复或标明兼容性边界，不擅自增加替代按钮／功能。后续开发从未完成项继续，保持公开 API、权限和签名边界；公开仓库／安装包发布另行执行。
