# SofaPad 统一产品文档

产品基线 **v2.5** · 对应应用 **0.9.3 开发预览** · 2026-09-12

本文件是产品范围、交互和验收的唯一开发基线。优先级为：用户最新补充 > [MVP 原稿 v0.2](archive/mvp-v0.2-original.md) > [旧蓝图 v1.3](archive/v0.1/product-blueprint.md) 中仍适用的工程约束。安装、协议和测试记录分别维护细节，不重复定义产品范围。

## 1. 定位与前提

Mac mini 连接电视，iPhone Safari 作为触控板和文字输入端。电视负责显示，手机负责输入，日常可以收起实体键鼠。只安装一个 Mac 菜单栏 App；App 内置网页与局域网服务，不依赖手机 App、云账户、Pages、CDN 或单独网站部署。

Mac 必须已登录、解锁、唤醒，SofaPad 正在运行，并完成辅助功能授权。Mac 网线、手机 Wi-Fi 可以，只要局域网互通。首次安装、重启后的登录和授权需要用户在 Mac 完成，不属于手机遥控流程。

手机不显示 Mac 画面；用户看电视确认指针、光标、选区和结果。运行目标 macOS 13+，目标浏览器 iPhone Safari（当前建议验证 iOS 17+）；最低实际兼容版本以真机结果为准。

## 2. 完整使用流程

1. 打开 Mac 上的 SofaPad：服务自动开启，菜单栏菜单里显示访问地址。
2. 首次在 Mac 上授予辅助功能权限；用手机浏览器打开该地址即可控制。同一局域网内任何设备都可以，先连上的一方获得控制权。
3. 进入整屏触控板，在电视上移动、点击和滚动；左上角设置调整手感。
4. 需要文字时先点选 Mac 的输入位置，再点击手机右上角鼠标／键盘图标切换按钮：输入面板从顶部下拉，iPhone 原生键盘从底部升起。
5. 中文选词、英文、Emoji 或系统听写完成后字符即时键入 Mac；删除显示 ⌫、回车发送真正的 Return，语音听写停顿约一秒后发送。
6. 用户看电视确认结果；点击面板以外的任意位置收起面板与键盘，回到触控板。
7. 锁屏／切后台后返回页面，自动尝试重连，继续接受新操作。

## 3. 手机界面

### 3.1 触控板模式

触控板铺满**网页可用视口**，无标题栏、底部工具栏或独立鼠标按键。普通 Safari 的浏览器栏与系统区域无法由网页占用。

触控板正常连接只常驻两个悬浮入口：左上角 48 × 48 CSS px 的“设置”按钮；右上角鼠标／键盘图标切换按钮。胶囊内仅保留鼠标轮廓与滚轮、键盘轮廓与少量按键，高亮当前模式，不附加箭头和文字。可访问名称说明切换目标。均避开系统安全区域，按钮不占用独立布局行，也不向 Mac 发送鼠标点击。连接异常、权限缺失时才显示提示。

设置仅含指针／拖动速度、滚动速度、自然滚动和恢复默认手感。指针默认 1.5×（可调 0.2–5.0），滚动倍率默认 0.3×（可调 0.05–5.0）；自然滚动默认开启。两个滑块都是 0–100 的行程，中点正好是默认值，左右两半各按对数刻度覆盖一侧，因此默认值两侧的手感分辨率一致、都能细调；越出范围的历史存档只夹紧、不丢弃。设置持久化，“恢复默认手感”重置这三项。移除遥控模式、模式选择及独立遥控速度；升级清理旧模式配置，保留已保存的触控板速度和滚动设置。

双指与边缘滚动统一应用基础系数 **0.4**，实际滚动位移为手指位移 × 0.4 × 已保存滚动倍率 × 方向符号。沿用 0.5.0 的减速，默认 0.3× 对应有效系数 0.12。指针和拖动速度不受该系数影响。

左右各 28 CSS px 窄条落指即进入纵向滚动，其外 48 px（合计与渐隐提示等宽的 76 px）为判定带：带内纵向多于横向就滚动，横向多于纵向仍是移动指针。滚动区覆盖可用视口高度，与触控板共用点阵底色，通过向内渐隐和细短标记提示范围，没有硬分割线；接触时仅对应侧渐变加深。悬浮按钮优先响应，滚动区不覆盖按钮。

### 3.2 输入模式

输入模式不切换页面：触控板始终铺满视口，输入面板从顶部下拉出现，包含单行文本框、其上方的飘出标签区与一行同步提示；右上角鼠标／键盘图标切换按钮保持不变。主机声明实时同步能力时不再显示粘贴与退格按钮；只有未声明该能力的旧主机才回退显示“贴入输入框”和左上角 48 × 48 CSS px 的退格图标，并使用多行草稿框。输入模式隐藏手感设置，不向 Mac 发送鼠标操作；输入时键盘图标高亮。

默认（实时同步）下文本框只有一行高，是“穿堂”式缓冲：已提交的字符立刻键入 Mac，先在输入光标处以略大于输入文字的字号保留约 0.5 秒，再沿光标位置向上飘出、淡出；删除显示 ⌫、回车显示 ↵ 并立即发送，因此不需要额外按钮。文本框本身保持空，只在 IME 选词时显示候选串；语音听写期间文字变灰表示尚未发送，停顿后发送并清空。点击面板以外的触控板任意位置、键盘右上角完成键或点击切换按钮都会收起面板与键盘回到触控板，收起那一下点击不产生鼠标操作；切后台、锁屏不收起。旧主机回退时，退格按钮每次点击向 Mac 当前焦点发送一次 Backspace（向后删除）按下／抬起，不带修饰键、不长按连发；它不删除手机文本、不改变草稿、不修改剪贴板、不查找或切换 Mac 焦点，点击保留手机文本框焦点及软键盘。未连接、未授权或缺少能力时禁用；断线不排队、不自动重发，由用户看电视确认结果。

切入输入模式必须在用户点击处理函数内同步 focus，适配 visualViewport 的高度及偏移，确保软键盘出现后输入、同步、切换仍可用。输入页在右上角共用按钮下方留出顶部空间；文本框、同步提示与底部按钮适配键盘后的剩余视口。切回触控时 blur 收键盘。切换、打开设置前清理当前手势；不得产生额外点击。

输入内容与飘出标签只驻留当前页面，不写 localStorage、日志或持久化文件；实时同步下文本已交给 Mac，手机侧不保留草稿（旧主机整段粘贴路径仍保留草稿）。断线或未授权时文本框只读并提示。关闭、刷新或系统回收页面后不承诺恢复。

## 4. 手势契约

### 4.1 触控板手势

| 手势 | 行为 |
| --- | --- |
| 单指滑动 | 相对移动指针，抬手重落后从 Mac 当前位置继续 |
| 单指轻点 | 一次左击 |
| 连续两次轻点 | 两次点击形成双击，第二击 count=2，不补发整组 |
| 双指轻点 | 所有触点抬起后仅一次右击，容许少量落指时间差 |
| 双指滑动 | 三方向（横、纵、斜）连续像素滚动，默认内容随手指方向移动 |
| 三指滑动 | 在 Mac 当前指针位置按住左键，跟随三指中心的相对位移拖动 |
| 单指长按 | 静止 500 ms 触发一次右击，无需抬手；后续移动／抬手不附加操作 |
| 左右边缘单指上下滑动 | 仅纵向滚动，抬手结束，不移动指针 |
| 轻点后第二次按住滑动 | 在双击加入时限内第二次落指，按住并滑动开始单指拖动，抬手释放 |

轻点初始容差 8 px、240 ms；第二指轻点加入窗口 120 ms，双击时间取 Mac 系统配置。双指滚动中心阈值 5 px。手感参数最终由真机校准，这些数值是初始实现参数。

单指明显滑动后不产生点击。第二指加入后停止单指移动；双指先抬一指时阻止余下触点触发新手势，全部抬起再开始。滚动后不右击；触控板避免浏览器滚动、缩放、选字和合成重复点击。

### 长按右击与双击按住拖动

单指落下后开始 500 ms 计时，8 px 内的小幅抖动允许继续等待。超出移动容差、加入触点、打开设置、切入输入、旋转、系统取消、捕获丢失、后台或断线立即取消计时；移动后回到起点不重新计时。触发一次右击后，本轮剩余移动和抬手不再发送操作。双指轻点右击继续保留。

“双击按住拖动”定义为：先轻点一次（正常左击），在 Mac 双击时间窗口内、距上次轻点 24 px 内第二次落指；第二次不抬起并移动超过 8 px 时进入左键拖动。进入拖动后不额外发送第二次 click，使用既有 drag begin/update/end/cancel 通道。第二次落指成立后保留拖动候选，不启动长按右击；若一直未移动而长时间按住后抬起，不补发点击。第二次快速抬起仍使用原来的双击判定。

单指拖动抬手立即释放；拖动中再加一指取消并释放，不转为滚动或三指拖动。两种拖动方式都沿用双端会话清理，不提供抬手续拖或拖动锁定。

### 三指拖动

- 先用单指定位；第三指须在首次落指后 180 ms 内、双指尚未开始滚动时加入。三指成立时重置中心，落指本身不移动指针、不点击。
- 三指中心移动超过 8 px 才开始：一次 leftMouseDown → 连续 leftMouseDragged。三指仅轻点无操作。
- 任意一指抬起，立即发送一次 leftMouseUp；其余触点全部抬起前不转为移动、滚动或点击。
- 已经双指滚动后加入第三指，取消滚动并等待全部抬起；第四指及更多触点取消当前手势。
- 模式切换、设置弹窗、旋转、pointercancel、捕获丢失、后台和断线清理。Mac 在会话关闭、心跳超时、协议错误、权限丢失、暂停和正常退出时独立尝试释放本应用的左键；不只依赖手机结束包。
- 不支持拖动锁定或抬手续拖。系统强杀、崩溃或已撤权后 OS 拒绝事件不属于可保证的正常释放路径。
- iPhone 系统三指编辑手势可能抢占触摸；返回触控时取消文本焦点有帮助，但不作为兼容性证明。正式可用必须通过目标 iPhone Safari 的横纵拖动及从输入模式返回后的实测。

### 4.2 边缘滚动

区域在落指时锁定。触控板中央起手后滑到任意边缘仍执行原指针／拖动手势；滚动区起手后滑出窄条仍只按纵向位移滚动。纵向累计移动超过 5 px 后开始，保留阈值内累积量；忽略横向位移，不合成惯性。边缘轻点、长按与纯横滑不产生操作，也不参加双击计数。

落指位置决定起手方式：最外侧 28 CSS px（窄条）无条件进入滚动，与渐隐提示等宽的 76 px 带内则是“先看方向”——首个采样方向明确（纵向或横向达到 2.5 倍）就地判定，否则再等几像素，累计 14 px 内纵向占多数即滚动，横向占多数则回到指针移动。这样拇指落在窄条外几像素、或起手前几像素抖动时仍会滚动，而不是悄悄变成移动指针；轻点、双击按住拖动与横滑保持原有行为。

滚动区仅支持单触点。滚动中加入任意第二指，或中央手势中加入滚动区触点，取消当前手势并等待全部抬起，不转换成其他手势。双指滚动和三指拖动均在中央触控区域起手。设置、输入切换、旋转、系统取消、捕获丢失、后台和断线清理当前滚动，沿用服务端释放保障。Safari 系统边缘手势可能抢占，需要真实设备验证。

### 4.3 网页原生反馈

控制面板、悬浮按钮、设置和状态提示禁止浏览器文字选中、拖动图像、长按菜单及点击高亮；触控区域禁止网页滚动和缩放。文本输入框保留原生选字、复制／粘贴菜单和编辑行为，退出输入时清除遗留选区。网页不能保证阻止操作系统保留手势。

## 5. 文字输入与执行

### 5.1 实时同步（默认，需主机声明 edit 能力）

输入框是单行“穿堂”式缓冲：已提交的字符立即键入 Mac 光标处，并在输入光标处以略大字号停留约 0.5 秒，再向上飘出、淡出；删除显示 ⌫、回车显示 ↵，同样即时发送。文本框只承载输入法与键盘的临时缓冲（IME 选词时照常显示候选串），提交后即清空。

- 只同步**已提交**文本：IME 候选与拼音缓冲留在手机；语音听写按“停顿即定稿”处理——识别中的文字以灰色留在输入框且不发送，说话停顿约 1.2 秒或结束听写时，这段文字才键入 Mac 并从光标处上浮、输入框清空；之后的识别修正只影响尚未发送的部分。含空格或汉字判为听写，纯拉丁字母的预编辑仍留在手机。
- 一次同步即一条消息：新字符发文本，空框中的删除键发一次退格，回车发送真正的 Return 按键（kVK_Return 按下／抬起），由目标应用决定换行、确认或提交。文本框始终保留一个零宽哨兵，使“空框”里的删除键也能被识别并向上显示 ⌫。
- 删除是否发给 Mac 只看**删除之前**的状态：输入法组合期间的退格只缩小手机候选串，绝不删除 Mac 内容；组合结束后的短暂窗口内也按输入法收尾处理。只有框本来就空时的删除键才发送退格。
- 不发送键码、修饰键或按键序列；不经过剪贴板、不抢焦点、不附加额外回车；撤销／重做不重放到 Mac。
- 单条消息 delete ≤1024、text ≤4096 UTF-8 字节；网页按 128 次退格／512 字节分片，顺序发送，先删后插。完整 JSON 消息上限 16,384 字节。
- 断线、切后台或未授权时文本框只读，重连后从空框开始，**不重放**断线期间的差异。手机不读取 Mac 控件内容，协议也不提供该能力，因此不承诺反向同步或恢复 Mac 已有文字。
- 光标位置与目标应用是否接受合成文本由 Mac 侧决定；Mac 光标须先停在目标输入框。
- 飘出标签只是本地反馈，不进入网络、日志或存储；开启“减少动态效果”时退化为纯淡出。

### 5.2 整段粘贴（未声明 edit 能力的旧主机）

发送已提交的完整文本、不发送候选缓冲，不 trim、翻译、改写、规范化或附加换行。IME 组合中点击粘贴先请求结束选词，等 compositionend 后的最终 input 更新，再读取文本；模式切换或后台取消未发送的等待，不留下延迟粘贴。

空字符串禁用；仅空格或换行也是有效文本。发送期间禁止第二次提交；结束后用户可主动再发。UTF-8 文本上限 12,000 字节，完整 JSON 消息上限 16,384 字节（转义也占空间）。超限明确提示，不自动截断。

Mac 以串行顺序执行：鉴权／请求校验 → 去重 → 写入 NSPasteboard → **仅写入成功后**按下和释放 Command + V → 返回状态。不会激活 SofaPad、扫描输入框、读控件内容、寻找焦点、全选或按 Enter；不恢复旧剪贴板。目标 App 决定粘贴、选区替换、拒绝或过滤行为。

| 结果 | 手机反馈与行为 |
| --- | --- |
| 剪贴板及粘贴指令已执行 | 短暂“粘贴指令已执行”，保留原文；不声称输入成功 |
| 剪贴板写入失败 | 明确未执行粘贴，避免粘贴旧内容 |
| 已发但断线／6 秒未获回执 | “请查看电视确认是否已粘贴”；保留原文，不自动重试 |
| 未连接／未发送 | 禁用或提示尚未发送，不排队 |
| 缺少权限 | 提示在 Mac 授权 |

每次主动提交生成 requestID（进程 epoch + 128-bit 随机值）。Mac 保存摘要与结果，跨 socket 重连保留；同 ID 同文本返回原结果，同 ID 异文本拒绝，不再次执行。至多 1024 个结果，不淘汰旧 ID 后重新执行。达到上限拒绝新请求；重启进程换 epoch，旧请求也拒绝。文本原文不进入服务日志或去重记录，系统剪贴板仍按正常应用行为保留内容。

## 6. Mac 应用与连接

原生菜单栏常驻，全部设置与操作都在菜单栏菜单里：状态、访问地址与“复制地址”、开启／停止服务、断开当前控制者、辅助功能权限、网络地址（仅多网卡时显示选择）、登录时启动、版本与退出。没有设置窗口，也没有配对窗口，不建设遥控配置中心。执行输入时保持后台，不抢焦点。

保留旧蓝图的工程基础：SwiftPM 单仓库、内置网页、原生 CGEvent、无遥测／云服务、安装到稳定路径后配置登录启动。服务随 App 启动自动开启，菜单里可随时停止或再开启。使用公开 macOS 生命周期通知；睡眠、显示器休眠或会话切换暂停，恢复后手机自动重连。Mac 主动“断开”不自动抢回，用户可按提示重连；菜单显示当前控制者数量。

页面后台主动结束连接；服务端约 6 秒无有效应用消息释放会话，前台重连重新建立 sessionID／seq。移动、滚动和拖动更新按帧累加，点击前先发此前更新；持续背压取消，不囤积或重放旧动作。

## 7. 通信与部署边界

服务随 App 启动自动开启，只监听选定 en* 以太网／Wi-Fi 的私有 IPv4 与固定端口 9876；不绑定 0.0.0.0；Host 只接受绑定 IP 与本机 `.local` Bonjour 名两个入口（不支持自定义域名），IPv6-only、VPN、特殊接口与公网穿透不支持。地址或主机名变化时自动按新地址重启服务。

**同一局域网内的任何设备打开页面即可获得控制权**：不做配对、不需要账号、二维码或证书，多台设备可以同时打开并控制（每个连接一个独立会话）；同时操作时以先开始的手势为准，其他设备的移动与点击会被忽略直到该手势结束。代价是明文的 HTTP/WS：局域网内的他人可以读取或篡改流量，产品所有者接受该风险，只用于可信家庭网络。

仍保留的边界：精确校验 Host 与 Origin（未绑定的主机名、跨站页面、DNS 重绑定都会被拒绝）、POST／WS 必须同源、不提供宽泛 CORS、最多 48 个并发连接、3 秒 hello、约 6 秒无有效消息释放会话。离线指保留家庭局域网但断开外网，不是断开 Mac 后仍能控制。协议 v2 限制会话、递增序号、有限位移、拖动／滚动生命周期、大小和频率，详见 [协议](../Protocol/README.md)。不开放通用命令、任意键码或剪贴板读取接口。

## 8. 明确排除

不做摇杆／速度控制式遥控模式、长按右击之外的长按操作、三指拖动之外的三指操作、四指手势、捏合、拖动锁定、独立左右键、方向键／快捷键栏、媒体控制、应用启动、宏、常用文本、主题／手势自定义、多 Mac 管理、远程画面／截图、两端同步编辑、剪贴板历史／恢复、自动全选／提交、互联网远控、开机／唤醒／登录／解锁。

旧版“使用 Mac 屏幕键盘完成输入”退出核心流程；用户仍可自行使用系统功能，但不作为本版实现或验收依赖。
