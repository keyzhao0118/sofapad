适用场景

鼠标够不到，手机就在手边。

01

客厅里的 Mac mini

Mac 连接电视，坐在沙发上打开视频网页、点击播放、拖动进度条和搜索片名，减少拿起实体键鼠的次数。

02

接大屏的 MacBook

看照片、浏览网页或翻阅文档时，在同一房间用手机移动指针、点击和滚动，操作结果直接看大屏。

03

需要输入几个字的时候

用熟悉的手机中文输入法选词、输入 Emoji，或通过手机键盘的听写功能输入搜索词，无需拿出实体键盘。

这是同一局域网里的鼠标与文字输入工具。手机不显示 Mac 画面，也不提供远程开机、解锁或跨公网控制。

完整功能

常用操作，留在一块触控板上。

整屏触控板

单指移动、轻点单击、快速双击；长按约半秒或双指轻点右击。支持三指拖动，也支持单指轻点后按住拖动。

左右边缘滚动

两侧窄区上下滑动即可滚动，也可以在中央双指滑动。边缘提示向内柔和渐隐，滚动时加深，让拇指操作更自然。

原生手机键盘

右上角一键呼出手机键盘，输入条固定顶部。选词后的文字即时键入 Mac 当前光标处，退格和回车也会发送。

按你的手感调整

独立调节指针与拖动速度、滚动速度，并选择自然滚动方向。滑块中点就是默认值，往两侧都能细调。

设置跟着 Mac 走

四项设置统一保存在 Mac：指针速度、滚动速度、滚动方向、屏幕常亮。重启后保留，手机重新连接自动读取，多台手机在线同步。

前台常亮开关

设置里可以手动开关。支持时使用系统常亮机制，否则尝试本地无声视频兼容保活；离开页面即停止，面板显示运行状态。

多设备接入

手机、平板或电脑浏览器都能打开同一地址。每台设备独立连接；手势冲突时先开始者优先，Mac 菜单可断开单个或全部设备。

轻量菜单栏 App

不占 Dock，网页与服务都内置。启动自动开启服务，显示主机名与 IP 地址；可以停止服务，也支持登录时启动。

无需云账户

控制流量留在局域网，不依赖云服务、账号或手机 App。应用不上传遥测、不自动更新，源码采用 MIT 许可。

安装与连接

三步，把手机连到 Mac。

  1. 1

    安装并打开 SofaPad

    下载 SofaPad-0.9.10.pkg，双击安装到「应用程序」，然后打开 SofaPad。它没有主窗口，菜单栏出现小图标就代表正在运行。

    先退出旧版再安装。更新后刷新手机页面即可；也可下载 ZIP，解压后把 App 拖进「应用程序」。

  2. 2

    在 Mac 授予辅助功能权限

    点菜单栏图标 →「授予辅助功能权限…」，到「系统设置 → 隐私与安全性 → 辅助功能」打开 SofaPad。首次授权与登录解锁需要在 Mac 上完成。

  3. 3

    手机浏览器打开菜单中的地址

    手机与 Mac 接入同一局域网，打开菜单显示的 http://<Mac 名>.local:9876/ 或 IP 地址。服务随 App 自动启动，连上后即可使用整屏触控板。

    Mac 接网线、手机连 Wi-Fi 也可以，只要互通。Safari 可通过「分享 → 添加到主屏幕」获得更完整的可用屏幕。

Mac 需保持已登录、解锁、唤醒；手机使用现代浏览器。当前安装包仅提供 Apple Silicon，Intel 用户需自行构建。

边缘不用贴得很准。 最外侧 28 px 落指即滚动，往内的渐隐判定带合计 76 px，纵向起手也会滚动；判定带内横向起手仍是移动指针。手势开始后锁定，不因跨区改变。

文字输入

中文搜索，用你熟悉的键盘。

  1. 先用触控板点击 Mac 上要输入的位置。
  2. 轻点手机右上角键盘图标，原生键盘呼出，顶部输入条淡入。
  3. 用手机输入法选词；提交后的文字直接出现在 Mac 光标处，手机输入框随即清空。
  4. 轻点右上角箭头、从箭头向下滑，或轻点空白触控区收起；这次收起操作不会变成鼠标点击。

退格与回车： 手机键盘的删除键发送 Backspace；回车发送真正的 Return。换行、确认还是提交，由 Mac 当前应用决定。拼音候选纠错保留在手机。

语音听写： 使用手机键盘自带的听写，停顿约 1.2 秒或结束听写后发送，尚未提交的识别修正不影响已发送内容。

顶部保持稳定： 输入条与收起按钮只淡入淡出，不随键盘高度上下移动。SofaPad 不读取 Mac 原有文字，也不会自动寻找输入框；断线的输入不自动重发。

手感与常亮

调一次，下一次连接还是你的习惯。

触控板左上角打开设置，修改后保存在 Mac，所有连接的手机共用。

指针与拖动速度
默认 1.5×，可调 0.2–5.0×。滑块往左更细，往右更快。
滚动速度
默认 0.3×，可调 0.05–5.0×；双指与侧边使用同一设置，并共用较慢的基础速度。
自然滚动
开启时内容跟随手指方向移动；关闭则反向。
屏幕常亮
默认开启，可手动关闭。系统常亮或兼容保活是否成功可在面板里查看；低电量模式、浏览器策略和媒体中断仍可能导致自动熄屏。
恢复默认
一次恢复四项设置，并同步到其他在线设备。

常亮只在页面前台运行，不阻止手动锁屏。兼容保活显示“运行中”不代表系统保证常亮，请按手机自动锁屏时长实测。

常见问题

开始使用前，你可能想知道。

需要在手机上安装 App 吗？

不需要。网页随 Mac App 提供，手机浏览器打开 Mac 菜单里的局域网地址即可。这个介绍网站用于了解产品和下载，不是遥控入口。

手机打不开地址怎么办？

确认 SofaPad 正在运行、Mac 已唤醒、服务已开启，两台设备在同一局域网。不要使用开启客户端隔离的访客 Wi-Fi；如果 .local 地址不可用，改用菜单里的 IP 地址，并检查 Mac 防火墙是否允许 SofaPad 接入。

能看到触控板，但 Mac 指针不动？

检查 Mac「系统设置 → 隐私与安全性 → 辅助功能」中的 SofaPad 开关。更新后若授权失效，可移除旧条目，重新授权并重启 SofaPad。也要确认 Mac 没有锁屏或睡眠。

安装时提示无法验证开发者，怎么处理？

当前开发预览使用本机 ad hoc 签名，安装包未签 Developer ID、也未公证。仅从本仓库 Release 下载，按 macOS 提示到「系统设置 → 隐私与安全性」允许打开。如果系统仍阻止，可参考安装教程中的 ZIP 安装方案；不要关闭整个系统安全保护。

能在外网用吗？有配对码吗？

只面向可信家庭局域网。没有账号或配对码，能够访问地址的设备就可以控制；通信是明文 HTTP/WS。不要映射到公网，也不要在不可信网络使用或输入敏感内容。

文字没有发到我想要的输入框？

SofaPad 把文字发到 Mac 当前焦点，不寻找或切换输入框。请先用触控板点中目标位置，再呼出手机键盘。发生断线或结果不确定时，先看大屏确认，未确认的输入不会自动重发。

可以同时用几台手机？

支持多个浏览器同时连接，不限制为单台控制器；服务有 48 个连接的资源上限。每台设备独立会话，同时发生的指针手势由先开始的一方优先处理。Mac 菜单可单独断开设备或断开全部。

为什么开了常亮仍然会熄屏？

标准常亮机制受浏览器支持与安全上下文限制，局域网 HTTP 通常会使用无声视频兼容方案，需要首次轻触激活。低电量或浏览器策略可能阻止保活；查看设置状态、轻触重试，并在实际手机上等待验证。

如何更新和卸载？

更新：先退出旧 App，安装新版，再刷新手机页面。卸载：退出 SofaPad，把应用移到废纸篓，并按需移除登录项与辅助功能条目。没有自动更新或后台云服务。

已经验证了哪些能力？
