# Mac 网页遥控器｜产品稿

版本：v0.2  
日期：2026-09-09  
状态：已收敛的首版功能范围，待开发与真机验证

## 1. 产品定位

Mac mini 连接电视后，通过 iPhone 网页完成鼠标操作和文字粘贴，让用户在日常使用中收起实体键鼠。

电视负责显示，手机负责输入。Mac 上运行常驻应用，在局域网内提供可访问的网页；iPhone 打开网页即可操作。

产品只有两个模式：**触控模式**和**输入模式**。以最少的控件完成操作，不添加与这两项核心能力无关的功能。

## 2. 使用前提

- Mac 已登录用户桌面、处于唤醒状态，常驻应用正在运行。
- Mac 与 iPhone 位于可相互访问的同一局域网。Mac 可以连接网线，iPhone 使用 Wi-Fi。
- 用户已在 Mac 上完成必要的辅助功能授权和网络访问设置。
- iPhone 使用 Safari 访问 Mac 提供的网页，不需要安装专用手机 App。
- 用户直接看电视确认指针位置、输入焦点和操作结果；手机不显示 Mac 屏幕画面。

首次安装、授权以及重启后登录，不属于本版手机遥控流程。

## 3. 核心使用流程

1. Mac 应用提供访问地址和二维码，用户用 iPhone 打开网页。
2. 网页默认进入触控模式。
3. 用户在手机上滑动、轻点或双指操作，控制电视上的 Mac。
4. 需要输入文字时，先用触控板点选 Mac 上的输入位置。
5. 点击模式切换按钮，进入输入模式，唤起 iPhone 原生键盘。
6. 用户在手机上完成打字、选词或系统听写。
7. 点击“贴入输入框”，将完整文字发送到 Mac。
8. Mac 写入剪贴板并模拟一次 Command + V，用户在电视上查看结果。
9. 点击模式切换按钮，返回触控模式。

## 4. 手机网页

### 4.1 触控模式

这是每次新打开网页时的默认界面。

- 触控板铺满网页可用区域，不放置标题栏、工具栏或独立鼠标按键。
- 仅保留一个悬浮的模式切换按钮，文案为“输入”。
- 切换按钮置于便于单手点击的位置，避开 iPhone 系统安全区域。
- 点击切换按钮只执行模式切换，不向 Mac 发送鼠标点击。
- “铺满屏幕”指网页可用视口；普通 Safari 的浏览器栏和系统区域不属于触控板。

#### 手势定义

| 手势 | Mac 行为 | 说明 |
| --- | --- | --- |
| 单指滑动 | 移动鼠标指针 | 使用相对位移；抬手后再次滑动，指针从原位置继续移动 |
| 单指轻点 | 左键单击 | 手指短暂接触后抬起，位移未超过轻点容差 |
| 单指连续轻点两下 | 左键双击 | 两次轻点满足时间与位置容差，形成一组双击 |
| 双指轻点一下 | 右键单击 | 允许两指落下、抬起存在少量时间差 |
| 双指滑动 | 滚动 | 支持垂直与水平滚动，采用自然滚动方向，内容跟随手指移动方向 |
| 三指滑动 | 左键拖动 | 识别到三指开始滑动后，在当前指针位置按下左键，再随手指相对移动；触点不足三指时释放左键 |

#### 手势判定要求

- 明显滑动后，抬手不得额外产生点击。
- 双指手势不得误触发单指左击。
- 双指滚动结束后，不得额外产生右击。
- 第二根手指加入后，停止按单指模式移动指针；双指操作中途只剩一根手指时，不立即转成鼠标移动，等待全部抬起后开始新手势。
- 第一次轻点正常执行单击；第二次符合双击条件时作为第二击，不额外补发一整组双击。
- 触控区域避免触发网页自身的滚动、缩放和文字选择。系统边缘手势或浏览器取消触摸时，结束并清理当前手势。
- 灵敏度、轻点容差、双击间隔等使用内置默认值，通过真机调试确定，不提供用户设置面板。

#### 三指拖动规则

- 先用单指将 Mac 指针移至目标，再三指落下并滑动；三指仅轻点不执行操作。
- 三指成立后，以三指中心的相对位移驱动指针。达到移动阈值时，先在拖动起点发送一次 `leftMouseDown`，再连续发送 `leftMouseDragged`，而非普通的 `mouseMoved`。
- 任意一指抬起导致触点不足三指时，发送一次 `leftMouseUp` 结束拖动；余下触点不转为点击、滚动或移动，全部抬起后才接受下一次手势。
- 容许三指落下存在少量时间差；尚未确定手势时避免误发点击或滚动。已经进入双指滚动后再加入第三指，不转成拖动，等待全部抬起后重新开始。
- 切换模式、浏览器取消触摸或网页进入后台时结束拖动。Mac 在检测到断线或连接心跳超时后，也必须释放由本应用按住的左键；不能只依赖手机发出结束消息。
- 本版不提供拖动锁定、抬手续拖或额外拖动按钮。
- Mac 拖拽事件有公共接口支持；iPhone 的三指撤销／重做等系统手势可能产生冲突。触控模式应解除文本框焦点并收起键盘，但不能据此保证消除系统手势。须在目标 iPhone／iOS Safari 上验证三指拖动能持续收到触摸事件，作为该手势正式可用的验收条件。

### 4.2 输入模式

点击“输入”后切换到输入模式，显示文本输入区，并在此次用户操作中主动聚焦以唤起 iPhone 原生键盘。

界面仅包含：

1. 文本输入区。
2. “贴入输入框”按钮。
3. 与触控模式共用的模式切换按钮，此时文案为“触控”。

布局应适配软键盘弹出后的可用高度，使文本输入区、发送按钮和切换按钮保持可用。此模式中的触摸用于编辑手机文字，不发送鼠标操作。

#### 输入规则

- 使用 iPhone 原生文字输入能力，支持中文选词、英文、标点、Emoji，以及系统键盘提供的听写。
- 发送的是文本框中已提交的完整文字，不逐键传输，不发送拼音候选过程。
- 输入法仍在组合文字时，先等待本次组合提交，再读取并发送最终文本。
- 不对文本做自动去空格、翻译、改写或其他内容变换。
- 空文本时，“贴入输入框”按钮不可用；非空文本按原内容发送，包括用户输入的空格和换行。
- 发送后保留原文，不自动清空，不自动返回触控模式。
- 切换模式不丢失当前草稿；返回触控模式时收起手机键盘。
- 发送过程中暂时禁止重复提交；请求完成后可再次主动发送。
- 本版不承诺网页被关闭或被系统回收后仍能恢复草稿。

## 5. Mac 常驻应用

### 5.1 最小职责

- 运行局域网网页服务，提供手机页面及实时通信通道。
- 提供访问地址和二维码，便于首次连接。
- 引导完成必要授权。
- 接收鼠标操作指令并发送系统鼠标事件。
- 接收文本，写入系统剪贴板并执行粘贴。
- 接收和执行指令时保持后台，不激活自身窗口，不抢走当前应用焦点。

Mac 端采用菜单栏常驻形式。界面限于连接入口、必要状态和退出操作；不建设额外的遥控配置中心。

### 5.2 文字粘贴逻辑

```text
收到文本请求
    ↓
检查连接身份、请求有效性与是否重复
    ↓
将完整文字写入 Mac 系统剪贴板
    ↓
写入成功后，模拟按下并释放 Command + V
    ↓
返回指令执行状态
```

行为约定：

- 不识别输入框，不扫描页面，不寻找输入目标。
- 不改变当前焦点，不自动全选，不直接覆盖控件全部内容。
- 不附加回车，也不自动触发搜索、发送或提交。
- 剪贴板写入失败时，不执行 Command + V，避免粘贴旧内容。
- 覆盖 Mac 原有剪贴板内容，本版不自动恢复。
- 最终结果由当前应用及其光标、选区和粘贴规则决定。

| Mac 当前状态 | 预期行为 |
| --- | --- |
| 普通文本框内有光标 | 在光标位置粘贴 |
| 文本框内选中部分文字 | 按应用规则替换选中文字 |
| 没有聚焦输入框 | 仍执行一次粘贴指令，由当前应用决定如何处理 |
| 目标限制粘贴、字符或长度 | 可能拒绝、过滤或截断，由用户查看电视确认 |

“贴入输入框”是用户操作文案，底层能力是向当前 Mac 应用执行粘贴，不保证任意控件都能接受输入。

## 6. 连接与必要反馈

可靠性处理在内部完成，不增加常驻操作控件。

- 正常连接时保持界面简洁；断开、连接失败或缺少授权时才显示简短提示。
- 手机锁屏、切后台或网络变化后，按连接可能中断处理；回到页面时自动尝试重连。
- 断线时清理手势和按键状态；重连后只接收新操作，不回放旧移动、点击或滚动。
- 断线期间不排队发送粘贴，不自动重试执行结果不确定的粘贴。
- 每次文本请求带唯一编号，Mac 对同一次请求去重，避免网络重传造成重复粘贴。
- 连接中断且结果不确定时，保留手机原文，提示“请查看电视确认是否已粘贴”。
- 指令完成可短暂提示“粘贴指令已执行”，不显示“输入成功”等无法验证的结论。
- 连接需具备最小必要的配对与鉴权，正式使用时保护通信内容；首次完成后不增加日常操作步骤。

## 7. 实现方向

| 部分 | 实现方向 |
| --- | --- |
| Mac 应用 | 原生菜单栏常驻应用，内嵌网页资源和局域网服务 |
| 实时通信 | 网页通过 WebSocket 发送鼠标及文本指令 |
| 网页手势 | 根据触点数量、位移和持续时间判断手势 |
| 鼠标执行 | 使用 macOS CGEvent 发送移动、左／右键、双击、滚动和左键拖动事件 |
| 文本执行 | 使用 NSPasteboard 写入文本，随后发送 Command + V 键盘事件 |

鼠标位移和滚动可合并连续更新，避免积压造成延迟；点击与粘贴不得随意丢弃或重复执行。具体参数以目标 iPhone、Mac 和局域网真机验证为准。

## 8. 明确不包含的功能

- 长按操作、三指拖动之外的三指手势、四指及更多手指手势、捏合缩放、拖动锁定和抬手续拖。
- 独立左右键按钮、方向键、回车键、快捷键栏。
- 媒体控制、应用启动、宏和常用文本。
- 灵敏度、主题或手势自定义设置面板。
- Mac 画面串流、截图、远程桌面预览。
- 自动识别输入框、读取输入框内容、同步编辑两端文字。
- 自动按回车提交或搜索。
- 剪贴板历史和自动恢复。
- 多 Mac 管理、跨互联网远控。
- 关机启动、睡眠唤醒、登录及解锁。

## 9. 首版验收标准

### 界面

- 新打开网页即进入触控模式，触控板占满网页可用区域，只显示模式切换按钮。
- 切换到输入模式可唤起 iPhone 键盘，按钮不被键盘遮挡。
- 模式切换不触发 Mac 点击，不丢失当前输入草稿。

### 触控

- 单指滑动能连续移动指针，抬手重划不导致指针跳回。
- 轻点、双击、双指右击分别产生预期行为，无额外点击。
- 双指垂直／水平滑动可滚动 Mac 中支持滚动的内容，手机网页本身不滚动。
- 两指非同时落下或抬起、滚动后抬手、手势被系统取消等情况不产生错误点击。
- 三指拖动可用于拖动窗口、拖移对象和选择文字，具体动作由指针下的目标应用决定；拖动时不误发右击或滚动。
- 三指非同时落下或抬起不导致指针跳变；任意一指抬起后结束拖动，剩余触点不触发其他操作。
- 拖动中切换模式、切后台或断网，Mac 能在取消通知到达或连接失效判定后释放左键，不出现持续按住状态。
- 真机验证三指横向及纵向拖动，并覆盖从输入模式返回后的场景；若系统手势持续抢占触摸，标记此手势兼容性未通过，不以接口可用代替真机验收。

### 文本

- 在普通可粘贴文本框中，中文、英文、标点和 Emoji 可完整传入。
- 在支持多行的文本框中保留换行；选中部分文字后粘贴，只按正常规则替换选区。
- 无输入焦点时不尝试寻找输入框，直接执行当前应用的粘贴行为。
- 写入剪贴板失败时不粘贴旧内容；同一请求重传不重复执行。
- 粘贴不抢焦点、不附加回车，发送后手机原文仍在。

### 完整场景

用户收起实体键鼠后，仅用手机完成：打开浏览器、点选搜索框、输入中文片名、粘贴、返回触控模式、点击页面搜索按钮、滚动并选择结果。手机锁屏再返回网页后，可重新连接并继续操作。

首版通过标准是：在用户常用的浏览器及桌面应用中，上述操作稳定、简单，且不需要增加新的界面控件。
