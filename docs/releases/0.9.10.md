# SofaPad 0.9.10 · 灰白立体图标与顶部键盘输入

把手机浏览器变成 Mac 的整屏触控板和文字输入端，适合客厅里接电视的 Mac mini，或接大屏的 MacBook。手机无需安装 App，Mac 与手机在同一局域网即可连接。

[中文产品介绍与操作方法](https://keyzhao0118.github.io/sofapad/) · [完整安装与排障教程](https://github.com/keyzhao0118/sofapad/blob/main/docs/installation.md)

## 下载与安装

- **推荐：`SofaPad-0.9.10.pkg`**，双击安装到「应用程序」。
- **备用：`SofaPad-0.9.10-macos-arm64.zip`**，解压后将 SofaPad.app 拖入「应用程序」。
- **校验：`SofaPad-0.9.10-SHA256SUMS.txt`**，与两个文件放在同一目录后运行 `shasum -a 256 -c SofaPad-0.9.10-SHA256SUMS.txt`。

适用于 **Apple Silicon（arm64），macOS 13 及以上**。这是开发预览：App 使用本机 ad hoc 签名，安装包没有 Developer ID Installer 签名，也未经过 Apple 公证。首次打开可能需要按系统提示到「隐私与安全性」允许打开。Intel 需自行构建。

更新前先退出旧版，安装后重新打开，刷新手机页面。辅助功能授权若失效，请移除旧条目后重新授权。

## 三步开始

1. 安装并打开 Mac 上的 SofaPad，菜单栏出现图标，服务自动开启。
2. 菜单栏 →「授予辅助功能权限…」，到系统设置里打开 SofaPad。
3. 手机与 Mac 接入同一局域网，用手机浏览器打开菜单显示的 `.local` 或 IP 地址。

Mac 需保持登录、解锁和唤醒；看电视或显示器上的结果，手机只负责输入。

## 这一版的变化

- **立体灰白图标**：保留触控板和光标轮廓，增加渐变、边缘高光与柔和阴影；菜单栏模板图保持简洁。
- **顶部固定键盘入口**：包含 0.9.9 改动，右上角键盘／收起按钮同位置切换，输入条固定顶部，只淡入淡出，不随系统键盘高度上下移动。
- **更完整的中文介绍**：GitHub Pages 展示场景、功能、安装、手势、输入、设置和常见问题，README 与截图同步更新。

## 现有功能

- 整屏触控：单指移动、轻点左击、双击，静止约 0.5 秒或双指轻点右击。
- 滚动与拖动：双指滚动、左右边缘单指滚动，三指拖动或轻点后再次按住稍停再滑动。
- 实时输入：手机中文选词、Emoji、删除与 Return 发送到 Mac 当前焦点；键盘听写停顿后发送，不读取 Mac 原有文字。
- 收起键盘：点右上角箭头、从箭头下滑或点空白触控区，不产生额外鼠标点击。
- Mac 保存设置：指针／拖动速度、滚动速度、自然滚动、屏幕常亮，连接后同步，多设备共用。
- 常亮开关：优先系统 Wake Lock，局域网 HTTP 使用无声视频兼容方案；页面隐藏时停止。
- 多设备独立连接、手势先开始者优先、单个或全部断开，支持登录时启动。

## 验证与使用边界

发布前 **129 项自动测试通过**（Web 93、Swift 23、HTTP/WS 13），桌面 Chromium 回归通过，覆盖顶部定位、视口压缩／恢复、IME、退格与回车、手势取消和设置同步。安装包解包与构建文件逐项一致，App 严格签名检查通过。

iPhone 原生键盘、三指系统手势、真实 Mac 输入、常亮效果和长时间电视操作仍需目标设备验证；系统策略可能导致手机熄屏。服务为明文 HTTP/WS，无账号或配对，仅在可信家庭局域网使用，不要映射到公网。没有屏幕镜像、远程开机、解锁或自动更新。
