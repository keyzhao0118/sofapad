手机变成电脑的触控板与键盘：移动、点击、滚动、拖动、中文输入。**只在电脑安装，手机使用浏览器；无需账号，无需编译。**

## Windows 第一次使用

1. 双击 EXE，按向导安装，从开始菜单打开 SofaPad。
2. 在右下角托盘找到 SofaPad 图标（可能在 **∧** 中），双击查看连接地址。没有主窗口是正常的。
3. 手机和电脑连同一家庭 Wi-Fi，将 Windows 当前网络设为**专用**。
4. 在手机浏览器输入 SofaPad 显示的地址。看到触控板后滑动一下，电脑指针跟着移动即连接成功。

[Windows 详细教程](https://github.com/keyzhao0118/sofapad/blob/main/docs/windows-installation.md)

## Mac 第一次使用

1. 双击 PKG 安装，从“应用程序”打开 SofaPad；图标在顶部菜单栏，没有常驻窗口。
2. 点击“授予辅助功能权限…”，在系统设置中开启 SofaPad。
3. 手机和 Mac 连同一家庭 Wi-Fi，在手机浏览器打开菜单显示的 .local 或 IP 地址。

[Mac 详细教程](https://github.com/keyzhao0118/sofapad/blob/main/docs/macos-installation.md)

**请使用自己电脑显示的局域网地址**（如 `http://192.168.1.23:9876/`，仅为格式示例）。GitHub Pages 是介绍与下载网站，不是遥控入口。

## 两个平台，一套操作

- 单指移动、轻点、双击；双指或长按右击。
- 双指双轴滚动、左右边缘单指滚动、三指拖动、轻点后再次按住拖动。
- 右上角手机键盘：中文、英文、Emoji、退格与 Enter；先点中电脑输入框，再开始打字。
- 左上角调整指针、滚动、自然滚动与手机常亮，设置由电脑保存，多部手机同步。
- Windows 托盘 / Mac 菜单栏提供开关服务、断开设备和登录启动。

## 更新与使用范围

更新前退出旧 SofaPad，下载对应系统的新版安装包覆盖安装，再刷新手机页面。Windows 保留用户设置；Mac 若辅助功能授权失效，移除旧条目后重新添加。

电脑需保持已登录、解锁、唤醒。Windows 管理员窗口与 UAC 安全桌面不受控。只用于可信家庭局域网：无配对、明文 HTTP/WS，不要映射到公网。软件不提供屏幕镜像、远程开机、解锁或自动更新。
