## 真实桌面验证状态

原生输入验证程序位于 `WindowsApp/tests/SofaPad.DesktopProbe`。本轮自动启动验证时，WebSocket 握手和 ping 成功，但测试编辑框未收到预期 Unicode 文本，因此**真实输入验证未通过**；尚未排除前台窗口归属与测试环境的影响。随后在人工激活验证窗口的过程中，用户按 Esc 停止 Computer Use，本轮不再继续桌面自动操作。不能把这次运行记录为真实中文、鼠标或拖动测试通过。

验证程序现会检查自己确实拥有前台窗口后才注入测试文本。可运行 `./scripts/test-windows.ps1 -Desktop` 重测；也可设置 `SOFAPAD_PROBE_MANUAL=1`，在隔离窗口点击“开始验证”。测试只向自己的窗口发送生成数据，不读取其他应用内容。
